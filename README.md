\# Git and GitHub Practice



\## About

This repository is created as part of the CodeHack Git assignment.



\## Objectives

\- Learn basic Git commands.

\- Understand Git branching.

\- Practise commits and pushing changes.

\- Learn how to fetch and pull updates.

\- Maintain proper documentation.



\## Git Commands

This repository demonstrates the use of Git CLI commands such as:

git init, git status, git add, git commit, git log, git diff,

git push, git pull and git fetch.
